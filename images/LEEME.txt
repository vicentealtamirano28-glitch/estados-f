SI QUIERES REEMPLAZARLAS
------------------------

Mantén los nombres de archivo (la parte antes del punto). La extensión puede
ser cualquiera de estas, y la página las prueba en este orden:

    .webp  ->  .jpg  ->  .png  ->  .jpeg

Si no encuentra ninguna, se muestra la ilustración de respaldo de la lata.
Nunca aparece el icono de imagen rota.

IMPORTANTE: la extensión debe coincidir con el formato real del archivo. Las
fotos llegaron como .jpg pero por dentro eran WebP; los navegadores lo toleran
porque detectan el formato por el contenido, pero el servidor las sirve con el
tipo equivocado. Se renombraron a .webp para que coincida.

Para saber qué es un archivo de verdad, sin abrirlo:

    file imagen.jpg


PROPORCIÓN
----------

El hueco es cuadrado (1:1), ajustado a las fotos actuales. Se usa
`object-fit: contain`, así que una foto de otra proporción NO se recorta ni se
deforma: solo queda con márgenes.

Si cambias a fotos verticales (4:5), ajusta esta línea en index.html:

    .can-stage { ... aspect-ratio: 1 / 1; ... }

a `aspect-ratio: 4 / 5;`


RECOMENDACIONES PARA FUTURAS FOTOS
----------------------------------

- Menos de 300 KB por archivo. Son cuatro y se cargan en la misma pantalla.
- Fondo transparente (PNG o WebP con alfa) si quieres que se vea el degradado
  de color de la tarjeta por detrás. Las actuales son opacas, así que muestran
  su propio fondo.
- Mínimo 1080 px de lado. Por debajo se ven borrosas en pantallas de alta
  densidad.


ATRIBUCIÓN
----------

Las fotos son de Pinda Kombucha. El sitio lleva el aviso de uso académico en el
pie y un `noindex` para no competir con el sitio real en buscadores. Si lo
presentas, conviene mencionar que las imágenes son de la marca.


AÑADIR MÁS HUECOS DE IMAGEN
---------------------------

Los nombres de archivo y el tono de color de cada sabor están en el array
FLAVOR_ART, dentro del tercer <script> de index.html:

    var FLAVOR_ART = [
      { file: "maqui-cacao", hue: 330 },
      ...
    ];

El orden debe coincidir con el de `product.flavors` en los textos.
